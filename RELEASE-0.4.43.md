# FishFinder 0.4.43 — network and information styling

The network chooser uses larger list rows and status text, dark high-contrast
surfaces, and shared rounded buttons placed lower in the panel. Wi-Fi identity,
preferred receiver, scan/connection policies and saved profiles are unchanged.

Traffic and ownship information use rounded information panels and blue heading
and Close controls. The Close touch target is taller and its hit testing matches.
Airport information uses the shared background, rounded identifier/radio panels,
and circular border. Existing frequencies, procedure data, warnings and colors
are unchanged. No altitude or GPS inference is added.

Native 800×800 previews inspected the network and aircraft layouts. Focused
network and airport regression tests cover the existing actions.
