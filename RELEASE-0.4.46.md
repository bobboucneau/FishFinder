# FishFinder 0.4.46 — Airport selector touch refinements

Vertical swipes anywhere on the airport entry screen now scroll the character wheel. Longer swipes advance more characters. Button taps and arrow hold-to-repeat still work; a swipe does not trigger the button underneath it.

The arrow button now reads **→ Select**. The airport name, code and position or distance preview sit directly on the screen without a background or border.

Install using the normal update prompt. No launcher change or extra reboot is required.
